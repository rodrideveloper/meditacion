# Sound files

This directory contains the audio assets used by the app for preview and alarm playback.

Current files:
- `angelical.mp3`
- `campana.mp3`
- `lluvia.mp3`
- `bosque.mp3`

Note: `campana.mp3`, `lluvia.mp3`, and `bosque.mp3` are currently copies of `angelical.mp3` (placeholders) so the UI can offer multiple choices immediately. You can replace them with real royalty-free audios keeping the same filenames.

Royalty-free sources:
- https://freesound.org
- https://pixabay.com/sound-effects
- https://mixkit.co/free-sound-effects
